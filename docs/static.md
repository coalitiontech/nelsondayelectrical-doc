# Static Page

This page type is for standard content pages (for example: About, Services, Contact-style informational pages) using the delivered design system.

## Implementation Notes

* Built in WordPress block editor with Greenshift/core blocks.
* Desktop design is the main reference.
* Mobile behavior is handled through responsive best-fit adjustments.

## Recommended Static Page Structure

* Intro/hero section with page title and optional subtitle
* Body content sections (text, image + text, icon lists, CTA strips)
* Optional final CTA section

## Editing Instructions

1. Go to `Pages` and select the desired static page.
2. Edit content directly in existing blocks.
3. Keep heading hierarchy consistent (`H1` once per page, then `H2/H3` as needed).
4. Replace images using WordPress media library (optimize file size before upload).
5. Preview before publishing.

## Layout and Style Rules

* Reuse existing section patterns from delivered pages whenever possible.
* Keep consistent spacing rhythm between sections.
* Do not create one-off typography styles unless approved.
* Use existing button styles/colors from the homepage system.

## Responsive Guidance

* Convert side-by-side sections to stacked layout on smaller viewports.
* Keep line lengths readable on mobile.
* Confirm image crop/focal points still make sense at narrow widths.
